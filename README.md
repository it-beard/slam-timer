# Таймер для сцэны

[Беларуская](README.md) · [English](README.en.md)

Паўнаэкранны таймер для паэтычных слэмаў, адкрытых мікрафонаў, пітчаў, дэбатаў і любых выступаў з рэгламентам. Вялікія лічбы, якія відаць з апошняга рада, арнамент у стылі вышыванкі, папярэджанні перад канцом і сігнал, калі час скончыўся. Працуе без інтэрнэту, ставіцца як дадатак, наладжваецца спасылкай.

**Жывая версія:** https://timer.itbeard.com

## Магчымасці

- **Вялікія лічбы** на ўвесь экран і «нітка» пад імі, якая карацее разам з часам. Да 9:59:59.
- **Папярэджанні.** Колькі заўгодна парогаў, напрыклад 60 і 15 секунд: ранейшыя робяць лічбы залатымі, апошні — чырвонымі з пульсацыяй і трыма «пікамі».
- **Канец часу:** надпіс (тыпова «Час выйшаў», можна свой) і пяць «пікаў». Ці рэжым перабору: пасля нуля лічбы чырвоныя і лічаць уверх, «+0:13», каб журы бачыла, наколькі выступоўца перабраў.
- **Паўза бачная з залы:** лічбы прыглушаныя, двукроп'е міргае.
- **Этапы.** Некалькі адрэзкаў запар, напрыклад выступ 3:00 і журы 1:00, з назвамі і аўтаматычным пераходам, калі трэба.
- **Секундамер** з сігналамі на адзнаках.
- **Гук і святло.** Гучнасць, цік на апошніх дзесяці секундах, успышка экрана ў канцы для шумнай залы, кнопка «без гуку» на клавішы `M`. Сігналы плануюцца ў аўдыякантэксце наперад, таму гучаць своечасова, нават калі ўкладка ў фоне.
- **Хуткі выбар часу:** лічбы `1`–`9` задаюць хвіліны, стрэлкі дадаюць ці адымаюць час, у тым ліку падчас адліку.
- **Спасылка з наладамі.** Адна кнопка капіюе адрас, які адкрые таймер з гэтымі ж наладамі на любой прыладзе. Зручна для закладак пад розныя фарматы.
- **Экран для залы.** Другое акно без кнопак для праектара; кіраванне з першага. Вокны сінхранізуюцца самі.
- **Выгляд.** Цёмная, светлая ці сістэмная тэма, свой акцэнтны колер, арнамент можна выключыць для нейтральнага выгляду. Загаловак на экране свой.
- **Мова інтэрфейсу:** беларуская і англійская, вызначаецца аўтаматычна, мяняецца ў наладах.
- **Афлайн і ўсталяванне.** Шрыфты ў рэпазіторыі, service worker кэшуе ўсё; таймер можна ўсталяваць як дадатак з браўзера і адкрываць без сеткі.
- **Дакладны адлік** ад `performance.now()`, экран не гасне падчас адліку (Wake Lock), клавішы працуюць у любой раскладцы, налады захоўваюцца ў браўзеры.
- **Без залежнасцей і зборкі:** HTML, CSS і JS. Гукі сінтэзуюцца праз Web Audio, арнамент генеруецца ў SVG з тэкставай схемы вышыўкі.

## Клавішы

| Клавіша | Дзеянне |
|---|---|
| `Space` | Старт / паўза |
| `Enter` | Перазапуск бягучага этапу |
| `R` | Скід |
| `Shift` + `R`, `Home` | Да першага этапу |
| `N`, `PageDown` | Наступны этап |
| `P`, `PageUp` | Папярэдні этап |
| `1`…`9`, `0` | Хуткі выбар хвілін (`0` = 10), калі таймер спынены |
| `↑` / `↓` | ± 1 хвіліна |
| `←` / `→` | ± 10 секунд |
| `M` | Выключыць / уключыць гук |
| `F` | На ўвесь экран і назад |
| `S` або `,` | Налады |
| `Esc` | Закрыць налады |

Стрэлкі ў спыненым таймеры мяняюць працягласць этапу, у запушчаным — час, што застаўся. Клавішы спрацоўваюць па фізічным размяшчэнні, таму `R`, `F`, `S` працуюць і ў беларускай ці рускай раскладцы.

## Спасылка з наладамі

Усё, што ёсць у наладах, можна задаць параметрамі ў адрасе. Кнопка «Скапіяваць спасылку з наладамі» робіць гэта сама, але спасылку можна напісаць і ўручную:

```
https://timer.itbeard.com/?seq=Паэт=3:00,Журы=1:00&warn=60,15&over=1
```

| Параметр | Прыклад | Што робіць |
|---|---|---|
| `t` | `t=3:00` | працягласць: `3` — тры хвіліны, `0:30`, `1:30:00` |
| `seq` | `seq=Паэт=3:00,Журы=1:00` | этапы, назвы неабавязковыя: `seq=3:00,1:00` |
| `auto` | `auto=1` | аўтаматычна пачынаць наступны этап |
| `over` | `over=1` | пасля нуля лічыць перабор |
| `end` | `end=Дзякуй!` | надпіс у канцы |
| `warn` | `warn=60,15` | папярэджанні, секунд да канца; `warn=` без значэння выключае іх |
| `sound` | `sound=0` | выключыць усе гукі; паасобку `warnsound=0`, `endsound=0` |
| `tick` | `tick=1` | цікаць апошнія 10 секунд |
| `flash` | `flash=1` | успышка экрана ў канцы |
| `vol` | `vol=50` | гучнасць, 0–100 |
| `title` | `title=Open+mic` | загаловак на экране |
| `theme` | `theme=light` | `dark`, `light` або `system` |
| `accent` | `accent=2a6fb0` | акцэнтны колер |
| `orn` | `orn=0` | без арнаменту |
| `lang` | `lang=en` | мова інтэрфейсу: `be` або `en` |
| `mode` | `mode=stopwatch` | секундамер; `warn` тады азначае адзнакі ад старту |
| `display` | `display` | экран для залы без кнопак і гуку |

Параметры дзейнічаюць на гэтую сесію і захоўваюцца, калі націснуць «Захаваць» у наладах.

## Як карыстацца на мерапрыемстве

1. Адкрыйце https://timer.itbeard.com на ноўтбуку, падключаным да праектара ці тэлевізара.
2. Націсніце `S`, задайце рэгламент і праверце гук кнопкай «Праверыць».
3. Націсніце `F`, каб разгарнуць таймер на ўвесь экран. Кнопкі і курсор схаваюцца праз тры секунды самі.
4. Перад кожным выступоўцам: `Enter` для перазапуску або `Space` для старту. Выступоўцу далі лішнія паўхвіліны: тройчы `→`.

Два экраны: у наладах націсніце «Адкрыць экран для залы», перацягніце новае акно на праектар і разгарніце яго клавішай `F`. Кіруйце з першага акна: стан сінхранізуецца імгненна, гук грае толькі ў акне кіравання.

Парады:

- Браўзеры не прайграюць гук, пакуль на старонцы не было хоць аднаго кліку ці націску клавішы. Першы `Space` гэта разблакуе, але лепш праверыць гук загадзя.
- У шумнай зале ўключыце «Успышка экрана ў канцы»: пяць «пікаў» могуць патануць у апладысментах.
- На iPhone Safari не падтрымлівае поўнаэкранны рэжым для вэб-старонак. Усталюйце таймер на галоўны экран, тады ён адкрыецца без інтэрфейсу браўзера. На iPad, Android і дэсктопах усё працуе.

## Запуск лакальна і афлайн

Спампуйце рэпазіторый і адкрыйце `index.html` у браўзеры. Сервер і зборка не патрэбныя.

```bash
git clone https://github.com/it-beard/slam-timer.git
open slam-timer/index.html
```

Жывая версія працуе афлайн пасля першага адкрыцця: service worker кэшуе старонку, скрыпты і шрыфты. У Chrome, Edge і Safari таймер можна ўсталяваць як дадатак праз меню браўзера.

Каб размясціць сваю копію, зрабіце форк і ўключыце GitHub Pages для галіны `main` (Settings → Pages).

## Як змяніць пад сябе

- **Колеры** — зменныя ў `:root` і `:root[data-theme="light"]` у пачатку `style.css`.
- **Арнамент** — масіў `MOTIF` у `script.js`: `#` асноўны колер, `o` дадатковы, `.` пуста. Схема паўтараецца па гарызанталі.
- **Тыповыя налады** — аб'ект `DEFAULTS` у `script.js`.
- **Мовы** — `strings.js`. Скапіюйце блок `en`, перакладзіце і дадайце `<option>` у `index.html`.
- **Рэліз** — пасля змен у файлах павялічце `VERSION` у `sw.js`, інакш браўзеры з кэшам убачаць новую версію толькі пасля яго абнаўлення.

## Структура

```
index.html             разметка і дыялог наладаў

fonts/                 Playfair Display (OFL)

```

## Падтрымка браўзераў

Патрэбны сучасны браўзер: Chrome і Edge 111+, Firefox 113+, Safari 16.4+. Wake Lock працуе ў Chrome, Edge, Safari 16.4+ і Firefox 126+; у іншых браўзерах таймер працуе, але экран можа згаснуць па сістэмным таймаўце.
